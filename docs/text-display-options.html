KvSpy - Prompt Text Display Options

Suggestions for showing message/segment boundaries in the detail panel

Option 1: Inline Markers
Add visual markers directly in the text stream to show where messages and segments begin.
System prompt (1,245 chars):
You are a helpful assistant... SYS_END
What is 2+2? USER_END
The answer is 4. ASSISTANT_END
Total: 3,456 chars | 3 segments
+ Simple, no UI complexity
- Text can be cluttered with many messages
- Hard to parse programmatically
Option 2: Metadata Panel + Clean Text
Show segment metadata above the text, keep text clean and readable.
Segments 3 messages, 2 tool calls
Breakdown System: 1.2KB, User: 45B, Assistant: 23B, Tool: 890B
Prompt text:
You are a helpful assistant... What is 2+2? The answer is 4. [TOOL_CALL: calculate(2+2)] [TOOL_RESULT: 4]
+ Clean text view
+ Clear metadata summary
- Metadata and text are separate
Option 3: Collapsible Sections
Organize text into collapsible sections by message type.
System (1,245 chars)
You are a helpful assistant...
User (45 chars)
What is 2+2?
Assistant (23 chars)
The answer is 4.
Tool Call - calculate (890 chars)
[TOOL_CALL data]
+ Organized, easy to navigate
+ Shows size per section
- More UI complexity
- Clicks needed to see content
Option 4: Structured JSON (API Level)
Return structured data in API, let UI decide how to render.
"prompt_segments": [ { "type": "system", "offset": 0, "length": 1245, "preview": "You are a helpful..." }, { "type": "user", "offset": 1245, "length": 45, "preview": "What is 2+2?" }, { "type": "assistant", "offset": 1290, "length": 23, "preview": "The answer is 4." } ]
+ Flexible, UI can render however
+ Machine-readable
- More API complexity
- Larger responses

Recommendation

Option 4 (Structured JSON) provides the best foundation - the API returns segment metadata, and KvSpy can implement Option 3 (Collapsible Sections) for UI. This gives:

  • Flexible API that future tools can use
  • UI that shows structure at a glance
  • Ability to expand/collapse as needed
  • Previews for quick scanning without loading full text
